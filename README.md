# Chord Roulette（コードルーレット）

2・4・8小節ループ用のコード進行（1小節に1コード）を、ボタンひとつでランダムに提案するWebツールです。
コード名（例: Am7）と度数表記（例: VIm7、IIm、♭VII）を同時に表示し、歌メロディの案も一緒に出します。

**サイト:** https://horiyuto.github.io/chord-roulette/

## できること

- 🎲 で進行を選び直し（Enter または R）、🎵 でメロディだけ作り直し（M）、▶／■ で再生・停止（Space）。アイコンにカーソルを合わせると英語の操作名が出ます
- 2／4／8小節から長さを選ぶ
- 各小節にメロディの音の高さと音名を表示し、コード・ドラムと一緒に再生します。メロディ部分をタップするとその小節だけ試聴
- 各小節のボタン: 🔒 固定して残りだけ選び直す（1〜8キーでも可）／🎲 その小節だけ選び直す／↶ その小節だけ前のコード・メロディに戻す（最大20回。キー変更や 🎲・🎵 の後も、変更前のコード名・音・メロディへ戻せます。今のキーとほかの小節はそのまま）
- 固定した小節は、キーがランダムに変わっても、🎵 を押しても、手動で変えても、コード名・音・メロディを保持します（例: AM7 は AM7 のまま）。度数表記は今のキーに合わせて変わります
- 主音を変えると、固定していない小節を同じ度数のまま移調。メジャー／マイナーや小節数を切り替えると、固定を解除して新しい進行を提案（このときは戻せません）
- テンポは 50〜180 BPM。「Style」で弾き方を11種類（白玉は Whole notes、アルペジオは Arpeggio）から、「Drums」でリズムを15種類または Off から選べます。再生中は次の小節から切り替わります。コード名をクリックすると単体で試聴
- スマホでは「Key」「Style」「Drums」の現在値をタップすると、ページ内に候補が開きます。候補をタップするとすぐ反映されます。
- アドレスバーのURLを共有すると、同じ進行・メロディ・キー・テンポで開けます
- 「History」を開くと表示中の進行が先頭にあり、☆を押すとお気に入りになります。1小節だけ変えた進行や共有URLから開いた進行も対象です。履歴とお気に入りはブラウザ内に保存します。★を付けた進行はそのときのメロディも残ります

↶ の操作履歴は、このページを開いている間だけ保持します。再読み込み、履歴・共有URLの呼び出し、メジャー／マイナー・小節数の切り替えでリセットされます。戻した進行自体は履歴・お気に入り・共有URLに残せます。

### 弾き方

| グループ | 弾き方 |
|---|---|
| 伸ばす | 白玉 ／ パッド |
| 刻む | 4分刻み ／ 8分刻み ／ シンコペーション ／ 裏打ち ／ ストローク |
| アルペジオ | アルペジオ ／ アルペジオ（3連） ／ アルペジオ（16分） ／ アルベルティ |

### ドラムのリズム

| グループ | リズム |
|---|---|
| 基本 | 8ビート ／ 16ビート ／ 4つ打ち ／ ハーフタイム ／ シャッフル |
| バラード | バラード ／ バラード（3連） |
| ダンス・ヒップホップ | ディスコ ／ ファンク ／ ヒップホップ ／ トラップ ／ レゲトン |
| ジャズ・ワールド | ジャズ（4ビート） ／ ボサノバ ／ レゲエ（ワンドロップ） |

### 提案の条件（「Options」を開くと変えられます）

| 項目 | 選択肢 |
|---|---|
| メロディ（Melody） | Calm（ゆったり・標準）／ Lively（細かく動く）／ Off（表示・再生しない） |
| 流れ（Feel） | Smooth（定番寄り）／ Balanced（標準）／ Random（ほぼ自由） |
| コードの響き | 3和音 ／ 7th ／ ミックス ／ テンション多め |
| ノンダイアトニック | なし ／ ときどき ／ 多め |
| 1小節目 | トニック（I／Im）から始める |
| キー | 全体提案時にランダムにする（固定も可） |
| マイナーの度数表記 | 主音基準（Im, ♭VI）／ 平行調基準（VIm, IV） |

ノンダイアトニックには、セカンダリードミナント、同主調からの借用（IVm、♭VI、♭VII など）、ドリアン由来の IV、ナポリの和音、経過和音が含まれます。
セカンダリードミナントの次は、高い確率で解決先のコードが来ます。

## 選び方のルール

完全なランダムではなく、「気持ちよく聞こえやすい進行」が多めに出るようにしています。ただし意外な組み合わせも残します。

- **定番の進行**: 王道進行（IV V IIIm VIm）、小室進行（VIm IV V I）、カノン進行、丸サ進行（IV III7 VIm I7）、ツーファイブ、アンダルシア進行（Im ♭VII ♭VI V）など。これらをもとに、ときどき1〜2小節を入れ替えたり、始まる位置をずらしたりします
- **つながりの自然さ**: V → I のように、4度上（5度下）への動きや、ドミナント → トニックの解決を選びやすくします。ループの継ぎ目も含めて判断し、1小節だけ選び直すときは前後の小節につながるコードを選びやすくします
- **自由枠**: Balanced では約15%を従来どおりのランダムで選びます

| Feel | 定番の進行に近い進行 | 自由枠 |
|---|---|---|
| Smooth | 約半分 | なし |
| Balanced | 約3割 | 約15% |
| Random | ほぼなし（従来の選び方） | すべて |

- 隣り合う小節で同じルートは続けない（最後の小節 → 1小節目のつなぎ目も含む）。ただし Smooth／Balanced では、定番の動き IV → IVm、I → I7（マイナーでは Im → I7）だけは許可
- 固定していないコードは「キーからの距離」で持ち、キー変更時は同じ度数のまま移調する
- ボイシングは、前のコードから指の移動が少ない転回形を選ぶ
- ドラムはコードと同じ BPM・小節境界でループし、再生停止で一緒に止まる（ボサノバは2小節でひと回り）

### メロディの作り方

歌いやすさを優先して、次のルールで作ります。歌詞をのせる前のたたき台として使ってください。

- 音域は B♭3〜F5（約1オクターブ半）。強拍（1拍目・3拍目）は、その小節のコードの構成音に置く
- 音はキーの音階から選び、順次進行（隣の音への動き）を多めに、大きな跳躍は少なめにする
- 4小節・8小節では同じリズムを繰り返して「フレーズ」に聞こえるようにし、最後の小節は長めの音で、そのコードの安定した音（ルート・3度・5度）に着地する
- コードを選び直した小節はリズムを保ったまま音を付け直し、キーを変えると同じ幅で移調する
- ドラムがシャッフル・バラード（3連）・ジャズのときは、メロディの裏拍も跳ねて鳴る

## ローカルで使う

`index.html` をブラウザで開くだけで動きます（ビルド不要）。

テスト:

```sh
node --test
```
