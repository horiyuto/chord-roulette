# コードルーレット

2・4・8小節ループ用のコード進行（1小節に1コード）を、ボタンひとつでランダムに提案するWebツールです。
コード名（例: Am7）と度数表記（例: VIm7、IIm、♭VII）を同時に表示します。

**サイト:** https://horiyuto.github.io/chord-roulette/

## できること

- 「ランダムに提案」でコードを選ぶ（Enter または R キーでも可）
- 2／4／8小節から長さを選ぶ
- 小節ごとに「固定」して、残りだけ選び直す（1〜8キーでも可）
- 「このコードだけ変える」で1小節だけ選び直す
- 主音を変えると、同じ進行のまま移調。メジャー／マイナーを切り替えると新しい進行を提案
- 再生（白玉／4分刻み／アルペジオ、テンポ 50〜180 BPM）。ドラムは「リズム」のプルダウンで、コードとは独立して15種類から選べます（なしも可。再生中に変えると次の小節から切り替わります）。コード名をクリックすると単体で試聴
- アドレスバーのURLを共有すると、同じ進行・キー・テンポで開けます
- 表示中の進行は履歴の先頭にあり、☆を押すとお気に入りになります。1小節だけ変えた進行や共有URLから開いた進行も対象です。履歴とお気に入りはブラウザ内に保存します

### ドラムのリズム

| グループ | リズム |
|---|---|
| 基本 | 8ビート ／ 16ビート ／ 4つ打ち ／ ハーフタイム ／ シャッフル |
| バラード | バラード ／ バラード（3連） |
| ダンス・ヒップホップ | ディスコ ／ ファンク ／ ヒップホップ ／ トラップ ／ レゲトン |
| ジャズ・ワールド | ジャズ（4ビート） ／ ボサノバ ／ レゲエ（ワンドロップ） |

### 提案の条件

| 項目 | 選択肢 |
|---|---|
| コードの響き | 3和音 ／ 7th ／ ミックス ／ テンション多め |
| ノンダイアトニック | なし ／ ときどき ／ 多め |
| 1小節目 | トニック（I／Im）から始める |
| キー | 全体提案時にランダムにする（固定も可） |
| マイナーの度数表記 | 主音基準（Im, ♭VI）／ 平行調基準（VIm, IV） |

ノンダイアトニックには、セカンダリードミナント、同主調からの借用（IVm、♭VI、♭VII など）、ドリアン由来の IV、ナポリの和音、経過和音が含まれます。
セカンダリードミナントの次は、高い確率で解決先のコードが来ます。

## 選び方のルール

- 隣り合う小節で同じルートは続けない（最後の小節 → 1小節目のつなぎ目も含む）
- コードは「キーからの距離」で持つため、キーを変えても進行は変わらない
- ボイシングは、前のコードから指の移動が少ない転回形を選ぶ
- ドラムはコードと同じ BPM・小節境界でループし、再生停止で一緒に止まる（ボサノバは2小節でひと回り）

## ローカルで使う

`index.html` をブラウザで開くだけで動きます（ビルド不要）。

テスト:

```sh
node --test
```
